# Research preview scope

[简体中文](MIGRATION_SCOPE.zh-CN.md) · [Home](../README.md)

This independently initialized, allowlisted repository (`chatgptpro-web-agent`) contains only a **bounded offline research subset**: local task-state and receipt code, generic launchers, synthetic protocol examples, offline security tests, bilingual guides, legal text, and a Windows CI workflow. The supported demo remains Windows with Python 3.12 and is offline.

Unsupported capabilities include an independently certified live ChatGPT browser send, a credential custodian, universal host automation, and a remote GitHub result writer. Existing code interfaces may expose experimental integration surfaces, but these have **no verified live-provider support claim**. This preview is not production-ready and is not endorsed by OpenAI.

This is not a full production release or a feature-for-feature claim, and it is not an approved public release. This clean-root repository must pass its own exact-head native Windows CI. Public distribution separately requires independently supported source and notice rights, brand and platform review, plus explicit publication approval. Repository visibility does not substitute for those gates. See [notices](../THIRD_PARTY_NOTICES.md).
