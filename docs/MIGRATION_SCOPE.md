# Research preview scope

[简体中文](MIGRATION_SCOPE.zh-CN.md) · [Home](../README.md)

This independently initialized, allowlisted repository contains only a **bounded offline research subset**: local task-state and receipt code, generic launchers, synthetic protocol examples, offline security tests, bilingual guides, legal text, and a Windows CI workflow.

Unsupported capabilities include an independently certified live ChatGPT browser send, a credential custodian, universal host automation, and a remote GitHub result writer. Existing code interfaces may expose experimental integration surfaces, but these have **no verified live-provider support claim**.

This is not a full production release or a feature-for-feature claim. This clean-root repository must pass its own exact-head native Windows CI. Public distribution separately requires independently supported source and notice rights plus explicit publication approval. See [notices](../THIRD_PARTY_NOTICES.md).
