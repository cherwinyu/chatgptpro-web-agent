# 研究预览范围

[English](MIGRATION_SCOPE.md) · [首页](../README.zh-CN.md)

本仓库（`chatgptpro-web-agent`）采用独立新建的 Git 历史和严格文件白名单，只包含**有限的离线研究子集**：本地任务状态及回执、通用进程入口、合成协议样例、安全回归测试、中英文说明、法律文本和 Windows CI。已支持的演示仍是 Windows 与 Python 3.12 的离线流程。

没有得到验收的能力包括真实 ChatGPT 网页发送、凭据保管、通用宿主自动化、GitHub 远端结果写入。遗留代码接口可能包含实验性集成入口，但这**不代表线上平台兼容已经获得验证**。本预览不表示可用于生产，也不是 OpenAI 的背书。

这不是正式生产版，也不保证与其他工程完全同功能，更不是已批准的公开发布。清洁根提交必须在自身精确版本上通过原生 Windows CI；正式分发仍需要组件级代码来源、第三方许可及通知审查、品牌与平台审查、最终发布授权。仓库可见性不能代替这些门槛。详见[第三方通知](../THIRD_PARTY_NOTICES.md)。
