# 研究预览范围

[English](MIGRATION_SCOPE.md) · [首页](../README.zh-CN.md)

本仓库采用独立新建的 Git 历史和严格文件白名单，只包含**有限的离线研究子集**：本地任务状态及回执、通用进程入口、合成协议样例、安全回归测试、中英文说明、法律文本和 Windows CI。

没有得到验收的能力包括真实 ChatGPT 网页发送、凭据保管、通用宿主自动化、GitHub 远端结果写入。遗留代码接口可能包含实验性集成入口，但这**不代表线上平台兼容已经获得验证**。

这不是正式生产版，也不保证与其他工程完全同功能。清洁根提交必须在自身精确版本上通过原生 Windows CI；正式公开仍需要组件级代码来源、第三方许可及通知审查、最终发布授权。详见[第三方通知](../THIRD_PARTY_NOTICES.md)。
